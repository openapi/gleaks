# Changelog

## 0.1.0 (unreleased)

First version: encrypted profiles, email identifiers, Have I Been Pwned checks in
direct and k-anonymity mode, consent before every scan, history, suggested
actions, `.deb` and Flatpak packaging.

GLeaks' own tools, usable with no API key: an index of 28 sites that checks where a
page exists for a nickname, and an exact-phrase web search. Identifiers can be
emails, nicknames or names. Sources run independently, and the Activity tab logs
each step.

GLeaks' tools run as slow jobs: one request at a time, pausable, resumable after a
restart, optionally in the background, and repeatable on a schedule.
